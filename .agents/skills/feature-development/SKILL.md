# feature-development

Przed zmianą wskaż ID wymagania i kryteria akceptacji. Odczytaj odpowiedni komponent i wywołania w App.tsx. Dodaj test obserwowalnego zachowania; dla napraw pokaż regresję. Zachowaj podgląd Vite i nie dodawaj zależności bez potrzeby. Uruchom npm run verify. Zaktualizuj macierz funkcji i SESSION HANDOFF. Błędy oraz brak testu runtime oznacz jawnie, bez DONE.
